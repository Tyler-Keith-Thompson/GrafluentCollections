Aho–Corasick

How do you find many patterns in a text while reading it only once?

Example: search “ushers” for he, she, his and hers. After reading “ushe” the automaton is in the state for “she”, so she ends here, and so does he, the end of “she”. Reading “r” next, “she” has no way on, so its failure link drops to “he”, which continues to “her” and then “hers”.

What it’s forMany patterns, one pass

An Aho–Corasick automaton finds every occurrence of every pattern in a text in one pass, in time proportional to the text’s length plus the number of matches, however many patterns there are. It suits scanning for a list of keywords, banned words, signatures or dictionary terms, where searching for each pattern in turn would read the text once per pattern.

The ideaA trie that knows where to fall back

The goto edges are a trie of the patterns: each state spells a prefix of some pattern. Each state also has a failure link to the state for the longest proper ending of its letters that is itself a prefix of a pattern. Reading a letter, the scan follows the goto edge for it if there is one; if not, it follows failure links until a state has one, or it reaches the root. The text pointer never moves back.

A match is reported wherever a pattern ends at the current state, or at any state its failure links reach, since those spell endings of what was just read. Aho and Corasick described the automaton in 1975 for searching bibliographies.

Where it breaksA fixed set of patterns

The automaton is built for one set of patterns; adding a pattern means building it again. For a single pattern, a simpler search such as Knuth–Morris–Pratt or the standard library’s does the same with less setup. When the text is fixed and the patterns change, index the text instead, with a suffix array or a suffix tree.

In SwiftThe operations above, in GrafluentCollections

import Tries

let patterns = ["he", "she", "his", "hers"]
let text = "ushers"

let automaton = AhoCorasickAutomaton<Character>(patterns: patterns)
let states = automaton.stateCount  // 10
let matches = Array(automaton.matches(in: text))
let found = matches.map { "\(patterns[$0.patternIndex]) at \($0.range)" }  // ["she at 1..<4", "he at 2..<4", "hers at 2..<6"]

let states = automaton.statesView
var gotos = Array(repeating: [Character: Int](), count: states.vertexCount)
var failures = Array(repeating: Int?.none, count: states.vertexCount)
for edge in 0 ..< states.edgeCount {
    let source = states.source(ofEdgeAt: edge), target = states.target(ofEdgeAt: edge)
    if let symbol = states.symbol(ofEdgeAt: edge) {
        gotos[source][symbol] = target  // a goto edge
    } else {
        failures[source] = target  // a failure link
    }
}
let links = failures.count { $0 != nil }  // 9
