Fenwick trees

How do you keep running totals current when any value can change?

Example: the sum of the first seven values, indices 0 to 6, reads only three cells. Cell 6 holds value 6, cell 5 holds values 4 and 5, and cell 3 holds values 0 to 3. Adding to value 2 changes three cells too: 2, 3 and 7, the cells whose ranges include it.

What it’s forTotals that update in a few steps

A Fenwick tree holds a list of numbers and answers “what do the first i add up to?” and “what do the values from a to b add up to?” while values keep changing. An array of running totals answers instantly but rewrites everything after a change; the plain values change instantly but must be added up on every question. A Fenwick tree does both in a number of steps that grows with the logarithm of the count: frequency tables, ranks and cumulative counts.

The ideaRanges cut by binary

There is one cell per value, in one flat array, and no pointers. Cell i holds the sum of a run of values ending at i. The run’s length is a power of two, set by the low bits of i + 1: odd-numbered positions hold one value, others two, four or eight. A prefix sum reads its own cell and then jumps to the cell just below the range it read, until it falls off the start. An add writes its own cell and then moves to i | (i + 1), the next cell whose range covers it, until it passes the end. Both walks take one step per bit. Fenwick described the structure in 1994 for arithmetic coding.

The arrows drawn are the second walk: the update tree, which Arborescence(tree) gives as a graph. Edit the values or the operations above and step through again.

Where it breaksSums, not minimums

A range sum is the difference of two prefix sums, which needs subtraction. A minimum or maximum has no inverse, so a Fenwick tree can’t give one over an arbitrary range. A segment tree can, and it also supports adding to a whole range at once, at the cost of twice the memory.

In SwiftThe operations above, in GrafluentCollections

import RangeTrees
import Trees

let values = [3, 1, 4, 1, 5, 9, 2, 6, 5, 3, 5, 8]
let operations: [FenwickOperation] = [.prefixSum(through: 6), .prefixSum(through: 11), .add(4, at: 2), .prefixSum(through: 6), .prefixSum(through: 3), .add(-5, at: 8), .prefixSum(through: 11)]

var tree = FenwickTree(values)
var history = [tree]
var answers: [Int?] = []
for operation in operations {
    switch operation {
    case .prefixSum(let index):
        answers.append(tree.prefixSum(through: index))
    case .add(let amount, let index):
        tree.add(amount, at: index)
        answers.append(nil)
    }
    history.append(tree)
}
let total = tree.sum(in: 0 ..< tree.count)  // 51

let updates = Arborescence(tree)
var next: [Int: Int] = [:]
for cell in 0 ..< tree.count {
    next[cell] = updates.parent(of: cell)
}
let root = updates.root  // 12
