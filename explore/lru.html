LRU caches

When a cache is full, which entry should it forget?

Example: a cache with room for three holds a, b and c. Looking up a moves it to the front, so when d arrives the cache forgets b, the entry used longest ago, and not a, the oldest one stored.

What it’s forKeeping the answers you are likely to need again

A cache keeps the results of slow work, a disk read, a network request or a long computation, so asking again is fast. Memory is limited, so a full cache must drop something, and the entry used longest ago is a good guess at the one least needed: what a program used recently it tends to use again soon. Databases, operating systems, web servers and image loaders use LRU or close variants.

The ideaA dictionary and a list

A hash table finds an entry by its key in constant time. The entries are also linked in a list in order of use, most recent at the front. Every hit or store unlinks its entry and puts it at the front, and an eviction takes the entry at the back, so every operation is O(1).

GrafluentCollections keeps the entries in one flat array, the list’s links as indices into it, and a table from key to index. Iterating the cache goes from most to least recent without changing the order, and RootedTree(cache) gives the list as a path.

Where it breaksScans and frequency

One pass over more data than the cache holds pushes out everything, including entries used constantly, for data read once. And recency is not frequency: an entry used a thousand times yesterday goes before one used once a minute ago. Policies such as LFU, 2Q, ARC and W-TinyLFU weigh frequency too, at some cost in bookkeeping.

In SwiftThe operations above, in GrafluentCollections

import Caches
import Trees

/// One operation of the page: store a value for a key, or look a key up.
enum CacheOperation: Equatable {
    case insert(String, value: Int)
    case lookup(String)
}

/// What an operation found or pushed out.
enum CacheOutcome {
    case stored(evicted: LRUCache<String, Int>.Entry?)
    case found(Int?)
}

let capacity = 3
let operations: [CacheOperation] = [.insert("a", value: 1), .insert("b", value: 2), .insert("c", value: 3), .lookup("a"), .insert("d", value: 4), .lookup("b"), .lookup("c"), .insert("e", value: 5), .lookup("a"), .insert("f", value: 6), .lookup("d"), .insert("e", value: 7)]

var cache = LRUCache<String, Int>(capacity: capacity)
var history = [cache]
var outcomes: [CacheOutcome] = []
for operation in operations {
    switch operation {
    case .insert(let key, let value):
        outcomes.append(.stored(evicted: cache.insert(value, forKey: key)))
    case .lookup(let key):
        outcomes.append(.found(cache[key]))
    }
    history.append(cache)
}
let recency = cache.map(\.key)  // ["e", "f", "c"]

let path = RootedTree(cache)
let depth = path.map { $0.height }  // 2
