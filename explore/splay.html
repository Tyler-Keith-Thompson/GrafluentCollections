Splay trees

What if a search tree reshaped itself around what you just asked for?

Example: insert 10 to 70 in order, which leaves a chain, then look up 10. The lookup brings 10 to the root and folds the chain roughly in half on the way.

What it’s forHot keys near the top

A splay tree keeps keys in order and moves every key it touches to the root. Keys that are used often stay near the top, so a workload that keeps returning to a few keys, or that walks through them in order, runs faster than the logarithm of the count suggests. Any long sequence of operations still costs a logarithm per operation on average. It also splits and joins at a key.

The ideaRotate in pairs, to the root

A splay tree records nothing about balance. After each search it splays: it rotates the key it found up to the root two levels at a time. When the key and its parent lean the same way, it rotates the grandparent first and then the parent; when they zig-zag, it rotates the parent and then the grandparent. The paired rotations are what matter. Besides lifting the key, they roughly halve the depth of every key on the path it came along, so a deep chain does not last.

Inserting splays the new key to the root. Removing splays the key up, takes it off, and joins its two subtrees under the largest key on the left. A search for a key that isn’t there splays the last key it reached. Sleator and Tarjan described the tree in 1985 and proved the average bound.

Where it breaksReads that write

A single operation can take as long as the tree is deep. A lookup that splays rearranges the tree, so it needs the tree mutable, and threads that share one need a lock around every such read. When every operation must be fast, or reads are spread evenly over the keys, an AVL or red–black tree is the safer choice.

In SwiftThe operations above, in GrafluentCollections

import BinarySearchTrees
import Trees

let operations: [SplayOperation] = [.insert(10), .insert(20), .insert(30), .insert(40), .insert(50), .insert(60), .insert(70), .access(10), .access(40), .access(10), .remove(50), .insert(80)]

var tree = SplayTree<Int>()
var history = [tree]
for operation in operations {
    switch operation {
    case .insert(let key): tree.insert(key)
    case .remove(let key): tree.remove(key)
    case .access(let key): tree.access(key)
    }
    history.append(tree)
}
let height = tree.height  // 7

let shape = BinaryTree(tree)
let root = shape?.root  // 80
