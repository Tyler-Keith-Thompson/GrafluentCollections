Suffix arrays and trees

How do you find any substring of a text without scanning the text?

Example: find “ana” in “banana”. In the suffix array, the suffixes that start with “ana” sort next to each other, “ana$” and then “anana$”, so two binary searches bracket them. In the suffix tree, the walk from the root spells out “a” and then “na”, and the two leaves below that point are the occurrences, at 3 and 1.

What it’s forAn index of every substring

Both structures index a fixed text so that any pattern can be found in time that depends on the pattern, not the text. They also answer questions that are hard without them: the longest repeated substring, the longest substring two texts share, and how many distinct substrings there are. Genome search, full-text indexes, data compression and plagiarism detection rely on them.

The ideaEvery substring starts some suffix

A substring is a prefix of some suffix, so indexing the suffixes indexes everything. The suffix array sorts the suffixes and keeps only where each one starts, a single integer per position, so the ones starting with a pattern sit in one block that binary search finds. Beside it, the longest common prefix of each neighbouring pair shows where suffixes share a start.

The suffix tree is the trie of all the suffixes with each chain of single children merged into one labelled edge. A pattern is a walk down from the root, one symbol at a time, and every leaf below where it ends is an occurrence. Its leaves, read left to right, are the suffix array. GrafluentCollections builds the tree in linear time with Ukkonen’s algorithm and the array with SA-IS.

Where it breaksMemory, and change

A suffix tree takes many times the memory of its text, and even the array needs an integer per symbol. Both are built for a fixed text, so an edit means rebuilding. A text that changes often, or a search that runs only once, is better served by a direct scan or, for many patterns at once, an Aho–Corasick automaton.

In SwiftThe searches above, in GrafluentCollections

import SuffixStructures

let text = "banana"
let patterns = ["ana", "na", "b", "nab", "a"]

let array = SuffixArray(text)
let tree = SuffixTree(text)
var ranges: [Range<Int>] = []
var starts: [[Int]] = []
for pattern in patterns {
    ranges.append(array.occurrences(of: pattern))
    starts.append(tree.occurrences(of: pattern).map(\.range.lowerBound))
}
let repeated = tree.longestRepeatedSubstring?.range  // 3..<6
